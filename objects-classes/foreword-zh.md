# 你不了解JS然而:对象和类 - 第2版
# 前言

凯尔·辛普森(Kyle Simpson)在解释艺术中有着无可比拟的辉煌.

2015年4月,我有幸为凯尔的书撰写了前言[你不知道联署材料:ES6和Beyond](https://www.oreilly.com/library/view/you-dont-know/9781491905241/)一个令人兴奋而细致的深度潜入新的JavaScript语言特征,这些功能甚至还没有被Ecma批准(这要到2015年6月才会发生),但已经走进了世界. 当时,在有意义的文献和教育资源方面还存在空白,我宣布,没有比这更好的人加强填补. 我支持我在2015年写的所有文章, 我于2022年来到这里,

在凯尔投入的时间、努力和资源方面,我们都更适合为自己和同龄人形成对JavaScript编程语言的更好理解:学习、磨练和提炼复杂的语义,使之成为易于消化的概念,这些概念可以以无限、繁多的方式建立。 这就是我们在这里所看到的:凯尔通过在各个层面消耗它而成为编程主题的专家。 通过探究新语言特征的语义,将它们从阴影中引出,将它们从弧形起源中释放出来,并将它们释放出来用于我们的消费和成长.

即使作为一个成功的专业软件工程师,我仍然把凯尔的作品放在手边. 有时这些主题有助于向队友和同龄人解释非常复杂的概念,而其他时候则作为我自己的复习,因为总有一些有趣的脱口秀或新的视角来获得.
