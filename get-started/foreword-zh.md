# 你不认识JS然而:开始 - 第二版
# 前言

我第一次看到一则推文, 宣传原著系列的人群资助运动, 我当然知道JavaScript! 那时我在JavaScript工作了多年, 和一些科技最大的名字, 所以我觉得应该从头到尾地看这个粗略的说法。

这本书的资金完成后,我观察到很多人非常兴奋地阅读了这本书集,我决定继续给它一个镜头——你知道,只是为了让大家知道,我确实知道,JavaScript。 有一次我钻进并倒在文本上,我经历了深刻的学习组合,惊喜,甚至一点点的愤怒. Kyle说了一些挑战我的世界观的话, 让我思考, 直到我意识到他说的是真的(虽然我永远不会向他承认!),

原来我不知道JavaScript。 我不知道为什么我采用了某些模式;我不知道JavaScript为什么在某些情况中表现得像它一样,我也不知道我所假设的语言有多细微. 许多事情我不知道 我不知道, 我更糟糕 作为一个开发者。

这是这本书系列的伟大之处。 这不仅仅是第一次有人拿起语言(虽然也是给他们的),而是所有想掌握工具的软件手工业者,他们想要了解他们的交易的进出,想要选择解决问题的适当方法.

我欣赏Kyle和他的作品 就是他被他周围的编程界的热门分子 所迷惑 这并不是说,他不知道 社区正在发生的事情, 而是说,它没有动摇 他追求最好的答案 对于正确的问题。 这常常使他与最新的“最佳做法”相矛盾,但实际上这正是你需要的:一个从时间影响中去掉的视角,并且只是谈谈基本真理。 这就是为什么这个系列是如此的好。 《你不知道JS》的第一版仍然准确, 鉴于JavaScript地貌的沙子在变化, 没有什么东西能承受时间的考验。

让我们谈谈第一本书本身, "开始吧" 你可能想跳过它,因为你可能认为 你已经"开始"了, 但这是值得读这个! 你会很惊讶JavaScript的基本构件里 有多深,多细微,多奇特, 在进入语言结构之前,你必须先努力这些基础。 真正了解JavaScript, 这正是你所需要的基础。

所以,做你的未来 自己一个忙 挖出这本书 并解开内部的知识。 这些坚实的基础将比任何框架都更有利于你; 那些来来去,但我们仍将写 JavaScript 自己在未来几十年。 开诚布公 挑战你的先入为主的观念

因为,我发现自己,你可能不认识JavaScript(yet).
